# World-Snapshot Org

This is the official github organization for [World-Snapshot](https://github.com/World-Snapshot).

## Projects

This projects officially supported by the team include: 

- [WaveGen](https://github.com/World-Snapshot/ControlWave) - the core World-Snapshot repo.
- [ControlWave](https://github.com/World-Snapshot/ControlWave) - the WebUI of the WaveGen model for easier training and control, WaveGen natively supports control, so just a WebUI is enough.
- [wsg](https://github.com/World-Snapshot/wsg) - the code of wsg/wsv maker (img2wsg converter) and wsg/wsv reader (player).
- [Project Page](https://world-snapshot.github.io) - the Project Page of World-Snapshot.
- [doc](https://world-snapshot.github.io/doc) - official documentation of World-Snapshot.
